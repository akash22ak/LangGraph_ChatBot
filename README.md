# 📌 Project Overview

This project is a development environment for building and experimenting with **LangGraph-based Large Language Model (LLM) applications**.

It demonstrates how **stateful AI workflows** can be built by combining **LangGraph**, **LangChain**, and **Streamlit** into reusable, modular components. The repository includes standalone workflow examples, multi-node graph implementations, and a chatbot interface featuring **real-time response streaming**, **multiple saved conversations**, and **SQLite-backed persistence**.

### 🎯 Project Objectives

- Build modular LLM workflows using LangGraph.
- Demonstrate graph-based orchestration instead of linear pipelines.
- Develop interactive chatbot interfaces using Streamlit.
- Showcase different conversational architectures and agent workflows.
- Provide reusable templates for future AI applications.

---

# 🎯 Problem Statement

Traditional LLM applications generally follow **linear execution pipelines**, making it difficult to handle:

- Complex decision-making
- Conditional execution
- Multi-agent collaboration
- Looping workflows
- Stateful conversations
- Error correction and retries

This project explores how **LangGraph's graph-based architecture** enables maintainable AI workflows by introducing explicit state management and modular execution paths.

# 🏗️ Project Architecture

The project is divided into three independent modules:

### 🤖 ChatBot

Contains the basic chatbot implementation for conversational interactions.

### 💬 ChatBot with UI

Implements Streamlit-based chat interfaces supporting:

- Live response streaming
- Multiple conversation threads, each identified by a thread ID
- Persistent history stored in SQLite (survives restarts)
- Auto-generated chat titles, plus rename and delete
- LangGraph backend integration

**How the database version fits together**

```text
Streamlit UI (streamlit_frontend_database.py)
        │  streams messages / manages chats
        ▼
LangGraph graph (langgraph_database_backend.py)
  START → chat_node → END
        │
        ▼
SQLite: ChatBot.DB
  ├─ LangGraph checkpoint tables   (full message history per thread)
  └─ chat_titles                   (title + created_at per thread)
```

### 🧠 LangGraph Model

A collection of standalone workflow examples demonstrating different graph-based execution patterns including:

- Conditional execution
- Prompt chaining
- Mathematical reasoning
- Sentiment analysis
- Creative content generation

The repository demonstrates multiple LangGraph workflow patterns.

### 🔹 State Graph Architectures

- Multi-node execution
- Conditional routing
- Stateful transitions
- Graph-based orchestration

### 🔹 Sequential Prompt Chaining

- Context passing
- Multi-step reasoning
- Output refinement
- Chained LLM execution

### 🔹 Interactive Streaming

- Token streaming
- Real-time responses
- Improved user experience

### 🔹 Multi-Conversation Management

- One LangGraph `thread_id` per conversation
- Conversations reloaded from the checkpointer on demand
- Titles generated by the LLM on the first message (with a fallback if generation fails)

# 🚀 How to Run the Project

## 1️⃣ Clone the Repository

```bash
git clone <repository-url>
cd LangGraph-ChatBot
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv myenv
```

### Windows

```bash
myenv\Scripts\activate
```

### Linux / macOS

```bash
source myenv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Configure Environment Variables

Create a `.env` file inside the project root.

```env
HUGGINGFACEHUB_API_TOKEN=your_huggingface_token_here
```

> `meta-llama/Llama-3.1-8B-Instruct` is a gated model. Request access on its Hugging Face page with the same account that owns the token.

If any of the standalone workflows in `LangGraph_Model/` use OpenAI or Anthropic models, also add:

```env
OPENAI_API_KEY=your_openai_api_key_here
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

---

## 5️⃣ Run Standalone Workflow

Example:

```bash
python LangGraph_Model/1_bmi_calculator.py
```

You can similarly execute any workflow inside the **LangGraph_Model** directory.

---

## 6️⃣ Launch the Chatbot UI

Persistent version (recommended):

```bash
streamlit run ChatBot_with_UI/streamlit_frontend_database.py
```

Earlier, non-persistent versions:

```bash
streamlit run ChatBot_with_UI/streamlit_frontend_streaming.py
streamlit run ChatBot_with_UI/streamlit_frontend.py
```
